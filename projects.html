ปพ1 (4เทอม)

โปรเจกต์

การแข่งขันเขียนโปรแกรมคอมพิวเตอร์

ได้เข้าร่วมกิจกรรมการแข่งขันเขียนโปรแกรมคอมพิวเตอร์ ประเภททีม ในงานสัปดาห์วิทยาศาสตร์แห่งชาติ ส่วนภูมิภาค ประจำปี 2569 ในวันที่ 17 สิงหาคม 2569 ณ คณะวิทยาศาสตร์ มหาวิทยาลัยศิลปากร โดยเป็นตัวแทนจากโรงเรียนราชวินิต นนทบุรี ร่วมทีมกับเพื่อนร่วมทีม การเข้าร่วมกิจกรรมครั้งนี้ช่วยฝึกทักษะการเขียนโปรแกรมและการแก้ปัญหาเชิงตรรกะ การทำงานร่วมกันเป็นทีมภายใต้ระยะเวลาจำกัด

แข่งขันศิลปหัตกรรม

ได้เข้าร่วมศิลปหัตกรรมครั้งที่ 73 โดยได้เข้าร่วมโครงงานวิทยาศาสตร์ ประเภททดลอง มีชื่อโครงงานว่า ศึกษาประสิทธิผลของแสงสีเขียวและแสงสีน้ำเงินต่อการเจริญเติบโตของผักกาดขาว ได้รับรางวัลเหรียญทองลำดับ9 รับหน้าที่วางแผนและทดลอง ซึ่งได้เรียนรู้การทำงานเป็นทีม ฝึกการคิดอย่างเป็นระบบตั้งแต่การออกแบบการทดลองจนถึงการวิเคราะห์ผล และถือเป็นก้าวแรกที่สร้างความมั่นใจในการเข้าร่วมกิจกรรมประกวดครั้งต่อ ๆ ไป

อบรมออนไลน์ค่าย Game Pee Blox Camp

ได้เข้าร่วมการอบรมออนไลน์ ณ ค่าย Game Pee Blox Camp ซึ่งได้อบรมค่ายเป็นระยะเวลา 3 วัน เกี่ยวกับการสร้างเกมผีในRoblox โดยการอบรมครั้งนี้ได้รับหน้าที่ในการคิดแผนและออกแบบตัวเกม ซึ่งได้เรียนรู้ฝึกเป็นผู้นำ การทำงานเป็นทีม ฝึกคิดอย่างเป็นระบบแก้ปัญหาเฉพาะหน้า และรู้การทำงานเบื้องหลัง

อบรมออนไลน์ค่าน Game Web Developer Camp

ได้เข้าร่วมการอบรมออนไลน์ ณ ค่าย Game Web Developer Camp ซึ่งอบรมเป็นระยะเวลา 4 วัน เกี่ยวกับการปูพื้นฐานHTML CSS JS และได้นำBoostrap5 ช่วยในการออกแบบตกแต่งเว็บไซต์ให้สวยงามมากขึ้น โดยการอบรมครั้งนี้ได้เรียนรู้การทำงานของโค้ดแต่ละภาษา และการคิดอย่างเป็นระบบ ได้มีการสร้างเว็บไซต์เกมเป่ายิงฉุบ ซึ่งสามารถดูโค้ดได้ที่GITHUB : https://github.com/Panwat989/webgamedevfle

อบรมออนไลน์ค่าย Introduction to Backend Developer

ได้เข้าร่วมการอบรมออนไลน์ ณ ค่าย Introduction to Backend Developer ซึ่งอบรมเป็นระยะเวลา 4 วัน เกี่ยวกับการปูพื้นฐานBackend โดยมีภาษาที่สอนคือ HTML JS และ Insomnia ช่วยในการออกแบบ ทดสอบ จัดการ API โดยการอบรมครั้งนี้ได้เรียนรู้การทำงานเบื้องหลัง ฝึกคิดอย่างเป็นระบบและการแก้ปัญหาเชิงตรรกะ ซึ่งสามารถดูโค้ดและผลงานได้ทางGITHUB : https://github.com/Panwat989/dev

อบรมโครงการ Pim Institute Of Management

เข้าร่วมโครงการอบรม PIM Young Creative Program ณ สถาบันการจัดการปัญญาภิวัฒน์ ได้เรียนรู้แนวทางการเรียนและการประกอบอาชีพของสาขาต่างๆ โดยเฉพาะสายเทคโนโลยีและคอมพิวเตอร์ ได้เห็นการประยุกต์ใช้เทคโนโลยีในงานจริง และได้ทดลองปฏิบัติงานกับเครื่องคอมพิวเตอร์ ทำให้ค้นพบว่าตนเองสนใจด้านวิทยาการคอมพิวเตอร์ และมั่นใจในการเลือกเรียนต่อสาขานี้
